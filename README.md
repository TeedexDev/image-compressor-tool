# Image Compressor Tool

A modern, web-based image compression tool built with React and Tailwind CSS. Compress your images while maintaining quality control with an intuitive interface.

## Features

- 🖼️ **Drag & Drop Upload** - Easy image uploading with drag-and-drop support
- 🎚️ **Quality Control** - Adjustable compression quality slider (10% - 100%)
- 📊 **Side-by-Side Comparison** - Compare original vs compressed images
- 💾 **File Size Display** - Real-time file size and compression ratio
- ⬇️ **Download** - Download compressed images instantly
- 📱 **Responsive Design** - Works on desktop and mobile devices

## Tech Stack

- React 18.3.1
- Tailwind CSS 4.1
- Vite 6.3
- TypeScript

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm (recommended) or npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/TeedexDev/image-compressor-tool.git
cd image-compressor-tool
```

2. Install dependencies:
```bash
pnpm install
```

3. Start the development server:
```bash
pnpm dev
```

4. Open your browser and navigate to the local development URL

## How It Works

The tool uses HTML Canvas API to compress images:

1. Upload an image using drag-and-drop or file selection
2. Adjust the compression quality using the slider
3. Click "Compress Image" to process
4. Compare the original and compressed versions side-by-side
5. Download the compressed image
